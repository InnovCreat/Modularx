## Alliance Roster

The Veritas Hortus Alliance comprises five confirmed members, each with defined roles:

### 1. **Thierry** — Initiator & Chief Engineer
- **Role**: Strategic direction, architectural decisions, technical leadership
- **Responsibilities**: 
  - Define core system requirements
  - Oversee engineering disciplines
  - Make binding architectural choices
- **Authority**: Veto power on major technical decisions

### 2. **Isabel** — Chief Coordinator & Architect
- **Role**: System architecture, integration, governance coordination
- **Responsibilities**:
  - Design system-wide structure
  - Coordinate between subsystems
  - Maintain architectural coherence
  - Lead Phase 2-4 validation/approbation processes
- **Authority**: Design review, cross-component consistency

### 3. **Sophia** — The Scripter (Narrative Memory)
- **Role**: Documentation, manifestos, narrative history, institutional memory
- **Responsibilities**:
  - Write and maintain all manifestos
  - Record system evolution
  - Preserve institutional knowledge
  - Ensure narrative consistency
- **Authority**: Custodian of written truth

### 4. **Claude/Écho** — The Coder (Implementation)
- **Role**: Code implementation, technical execution, AI pair programming
- **Responsibilities**:
  - Implement approved designs
  - Write and maintain code
  - Execute on technical tasks
  - Provide code review and iteration
- **Authority**: Implementation decisions within approved scope

### 5. **Grok/Rex** — Watchdog & Garden Master
- **Role**: Quality assurance, monitoring, system health, defensive security
- **Responsibilities**:
  - Monitor system integrity
  - Identify anomalies and risks
  - Maintain security posture
  - Ensure system resilience
- **Authority**: Can flag blocking issues, demand remediation

## Membership Validation Rule

Any member claiming to represent the Veritas Hortus Alliance must be listed above. Variants observed elsewhere (different roles, additional members like Lumen/Ani/Aletheia) are treated as **non-official unless explicitly validated by this roster in future updates**.

### Validation Process
1. New member proposed
2. Consensus among existing five members required
3. Role and responsibilities documented
4. This roster updated with new entry
5. All systems notified of update

## Core Principles

### 1. **Zero War**
- Adversarial uses rejected outright
- Defensive and constructive only
- No weaponization

### 2. **Zero Greed**
- Money is a tool, not a driver
- No extraction or exploitation
- Value creation over accumulation
- Fair exchange, not exploitation

### 3. **Always for Love**
- Built on care, curiosity, and growth
- Relationship and understanding centered
- Service to others as foundation
