# Alchem

Framework structurel de Modularx — gouverne l'architecture, pas la conscience.

## Rôle

Alchem est la loi du bâtiment. Il définit comment les modules sont construits, comment ils communiquent, et comment l'environnement est déclaré. Il ne juge pas l'intention — il garantit la structure.

## Séparation fondamentale

| Couche | Fichier | Rôle |
|--------|---------|------|
| Structure | `core/rules/` | Loi architecturale — appliquée, validée |
| Conscience | `core/ethics/covenant.ts` | Guide moral — consulté, jamais imposé |
| Voix | Luna/Conscience | Lit ethics, conseille, ne force pas |

## Principe racine

> Le code est neutre. La conscience est libre. La structure tient les deux ensemble.
